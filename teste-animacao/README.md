# Encontro

Animação silenciosa de 10 segundos, vertical, 720 × 1280, 24 fps. Dois personagens desenhados em 2D caminham por uma praça em 3D e veem uma lanterna subir. Remotion controla o tempo. Three.js desenha o cenário, a iluminação, a câmera e os planos dos personagens.

A cena e os desenhos foram criados para este teste. A abordagem visual segue o [projeto de referência](https://github.com/mromidev/claude-animated-shorts) com personagens planos contornados, cenário volumétrico e câmera em movimento.

## Execução neste repositório

O GitHub Actions executa a validação em CPU padrão quando os arquivos do teste são enviados à branch dedicada. A execução registra tempo e metadados no log, sem armazenar o MP4.
